Cuyahoga Delinquent Multifamily Finder

Paste or upload a Cuyahoga County delinquent-tax list. The app extracts parcel numbers, checks official county parcel/GIS data, and surfaces duplexes, triplexes, and 4+ unit properties.

Open County Delinquent List
A parcel is treated as tax-delinquent because it appears in the county delinquent list you load. Use the MyPlace button on each result to verify the current tax record before contacting an owner or making an offer.
Sources: delinquency = the official county list you import; property type/units/address = Cuyahoga County Open Data Parcels. This tool does not invent delinquency when a parcel is not in your imported list.
