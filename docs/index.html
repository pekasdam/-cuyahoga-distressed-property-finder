Connect the Run button

This is a one-time setup. After this, Run Scan Now starts the GitHub scan automatically.

  1. Open the pre-filled GitHub token page below.
  2. Under Repository access, choose Only select repositories and select -cuyahoga-distressed-property-finder.
  3. Leave Actions: Read and write selected, generate the token, and copy it.
  4. Come back here, paste it below, then tap Save & Run.
Open one-time GitHub setup

The token stays on this device and is also saved as a first-party cookie so iPhone can carry it into a newly installed Home Screen app; it is not written into the public GitHub repository. Use a fine-grained token limited to this repository and Actions only.
